Caddyを使ってみる


概要

簡単なリバースプロキシが欲しかった。


インストール

brew install caddy



使い方

caddyfileと呼ばれるテキストに設定を書いて使う。


:18080 {

    # HTTP Python server

    handle_path /show-ref/* {

        reverse_proxy 127.0.0.1:8080

    }


    handle_path /get/* {

        reverse_proxy 127.0.0.1:8080

    }


    handle_path /search-ref/* {

        reverse_proxy 127.0.0.1:8080

    }


    # gRPC gRPCServer

    handle {

        reverse_proxy h2c://127.0.0.1:50051

    }

}


ざっくりこんな感じ。gRPCも含めて対応できる。
